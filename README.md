# Fly Away Travel – Frontend (CS2031 Semana 14)

Aplicación web SPA desarrollada con **React 19 + TypeScript + Vite** que consume la API REST de reserva de vuelos **Fly Away**.

## Requisitos previos
- Backend de Fly Away corriendo en `http://localhost:8080` (`./mvnw spring-boot:run` con JDK 26).
- Node.js 20.19+ o 22.12+.

## Instalación y ejecución

```bash
npm install
npm run dev
